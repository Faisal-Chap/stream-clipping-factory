# Security

Stream Clipping Factory is a single-operator application. Keep the portal on loopback and use a trusted SSH tunnel for remote access. Anyone with operator access can manage media, accounts, and publishing.

Keep provider keys in the configured credential vault. Keep the Factory workspace, databases, provider logs, browser profiles, and raw recordings outside Git. Use a demo workspace when recording a public walkthrough.

Report vulnerabilities privately through GitHub’s **Security → Report a vulnerability** for the repository. Include affected versions and a minimal example using synthetic media and test credentials.
